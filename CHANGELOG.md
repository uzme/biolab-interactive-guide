# BioLab Interactive Guide — Changelog

## [1.0.0] - 2026-08-16
### Added
- 100 Biotechnology devices catalog with 10 specialized categories and pagination (12 items per page).
- Original Pure CSS 3D Animated Carousel.
- 16-Section deep learning dossiers for every equipment item with PDF export functionality.
- Browser `localStorage` Bookmarks feature and right-side collapsible `BookmarksSidebar`.
- PWA Offline support with `manifest.webmanifest`, `sw.js`, and `OfflineManager` package controller with online/offline status indicator.
- Automated GitHub and Google Drive synchronization workflow (`sync_release.mjs`) restricted to the designated `Biotexnologiya yangi / Loyiha 1` folder.
- Comprehensive reproducibility documentation suite (`PROJECT_MANIFEST.md`, `ARCHITECTURE.md`, `DATABASE.md`, `REPRODUCTION.md`, `AI_HANDOFF.md`, `CURRENT_STATE.md`, `PROJECT_INVENTORY.md`, `DECISIONS.md`, `TROUBLESHOOTING.md`, `SECRETS_REQUIRED.md`, `.env.example`).
