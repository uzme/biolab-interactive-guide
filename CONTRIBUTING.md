# Contributing

Thank you for helping improve BioLab Interactive Guide.

## Before opening a change

Please check the existing documentation and open an issue for substantial feature proposals. Small documentation, accessibility, test, and focused UI improvements can be submitted directly as a pull request.

## Local validation

Run the following commands before submitting a pull request:

```bash
pnpm check
pnpm test
pnpm build
```

## Pull requests

Keep pull requests focused, describe the user-facing result, and include screenshots for visual changes. Do not commit credentials, private data, generated dependency directories, or local environment files.
