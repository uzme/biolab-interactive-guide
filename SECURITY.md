# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Contact the repository owner privately through the contact method listed on the [GitHub profile](https://github.com/uzme).

Include a clear description, affected files or routes, reproduction steps, and the potential impact. Do not include secrets or personal data in the report.

## Scope

This project is an educational web application. Reports involving exposed credentials, unsafe input handling, dependency vulnerabilities, authentication, or unintended data exposure are especially important.
