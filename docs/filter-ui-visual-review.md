# Katalog qidiruv va filtr interfeysi — mobil tekshiruv

2026-08-15 kuni mobil katalog ko‘rinishi tekshirildi. Qidiruv paneli nom/manufacturer qidiruvi, model qidiruvi va kategoriya tanlashni bir joyga jamlaydi. Model filtri `CFX96` qiymati bilan ikki mos rekordni qaytardi; kategoriya bilan birgalikda ishladi.

Keyingi dizayn qatlamida LAB-01 16-qadamli SOP relsi sahifaning asosiy vizual yo‘nalishi bo‘lib qoladi. Kartalardagi rasm foydalanuvchi talabiga ko‘ra saqlanadi, ammo model/manufacturer/manual bandi, SOP kodi va kategoriya signali uni laboratoriya protokoli rekordi sifatida yanada aniq belgilaydi.

Katalogning uzun oqimida kategoriya zonalari va texnik ajratkichlar ritmni kuchaytirishi kerak. BioLab mikromatni reklama tilidan ko‘ra SOP, operator va laboratoriya-trening tiliga yaqin bo‘ladi.
