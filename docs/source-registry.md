# BioLab — rasmiy o‘quv manbalari reyestri

Ushbu reyestr qurilma sahifalaridagi **“Ishonchli o‘quv manbalari”** bo‘limini faqat ishlab chiqaruvchi yoki rasmiy texnik manbalar bilan to‘ldirish uchun ishlatiladi. Modelga xos ma’lumot berishda tegishli modelning yangilangan qo‘llanmasi ustun hisoblanadi.

| Ishlab chiqaruvchi / resurs turi | Rasmiy resurs | Platformadagi qo‘llanishi |
|---|---|---|
| Thermo Fisher Scientific | https://www.thermofisher.com/us/en/home/life-science/lab-equipment/lab-equipment-learning-center/lab-equipment-resource-library/manuals-by-product-type.html | Manual qidiruvi: model, model seriyasi, katalog raqami yoki mahsulot turi bo‘yicha. |
| Agilent Technologies | https://www.agilent.com/en | User manual, application note, video, technical overview va trening resurslari uchun rasmiy qidiruv nuqtasi. |
| Eppendorf | https://www.eppendorf.com/us-en/download-center | Download Center, servis, kalibratsiya, produkt guruhlariga mos qo‘llanma va trening resurslari. |
| Shimadzu Nexera Support | https://www.ssi.shimadzu.com/products/liquid-chromatography/hplcuhplc/nexera-series/support.html | HPLC/UHPLC uchun user manual, applications, analysis basics va support yo‘nalishi. |

## Tekshirilgan faktlar

- Thermo Fisher manual arxivida qo‘llanmalar model/model seriyasi, order/catalog raqami yoki mahsulot turiga ko‘ra qidiriladi; ishlab chiqarish sanasi bo‘yicha mos revision tanlanadi.
- Agilent rasmiy sahifasida user manuals, application notes, video, technical overview, training va support resurslari mavjud.
- Eppendorf resurs markazi servis, kalibratsiya, turli produkt guruhlari bo‘yicha yordam hamda training/education havolalarini ko‘rsatadi.
- Shimadzu Nexera support sahifasida user manual, technical information, analysis basics, webinar va technical support yo‘nalishlari mavjud.

## Kontent siyosati

Modelga xos tugma, parametr, limit yoki troubleshooting qadami faqat shu modelning rasmiy manuali yoki ishlab chiqaruvchi application note asosida kiritiladi. Umumiy bilimlar barcha holatda “umumiy o‘quv yo‘riqnomasi” sifatida belgilab beriladi.
