# Mobil yuqori panel ikonkalari — vizual audit

**Sana:** 2026-08-23  
**Viewport:** iPhone uslubidagi 390 × 844 px  
**Holat:** PASS

Mobil yuqori paneli endi alohida-alohida, bir-biriga o‘xshash aylana ikonkalardan iborat emas. Menyu uchun chuqur teal action-karta, BioLab/LAB-01 identifikatori va yagona mint action-klaster ishlatiladi. Klaster ichida internet holati indikatori, offline paket, rang mavzusi, saralanganlar va filtr boshqaruvlari o‘z o‘rnida saqlangan.

Vizual tekshiruvda header bir qatorda qoldi, action-klaster 390 px ekranda kesilmadi, ikonkalarning kontrasti o‘qiladigan bo‘ldi va hero blok bilan bir xil precision-biotech vizual tilida ko‘rindi. Offline paket boshqaruvi 320–360 px ekranda ham yashirilmaydi; bu holatda uning, mavzu, saralanganlar va filter boshqaruvlarining semantik kontrakti 320 px, 375 px va 390 px regressiya orqali tekshiriladi.
