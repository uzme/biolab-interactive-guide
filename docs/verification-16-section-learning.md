# 16 bo‘limli o‘quv markazi — tekshiruv qaydi

**Tekshiruv sanasi:** 2026-08-15

PCR namunaviy sahifasi `BIO-001` uchun ochildi va tekshirildi. Ko‘rinish faqat o‘quv kontentiga qaratilgan: sahifada 3D viewer, 2D sxema, hotspot yoki model-preview bloki yo‘q.

| Tekshiruv | Natija |
|---|---|
| 16 bo‘limli chap navigatsiya | Mavjud, 1/16 progress bilan |
| O‘zbekcha nom, original nom, manufacturer va model | Mavjud |
| Keyingi bo‘lim oqimi | Mavjud |
| Xarid ma’lumoti | Asosiy o‘quv oqimidan keyin alohida accordion modulida |
| 3D / 2D ko‘rinishlar | Olib tashlangan |

Qo‘shimcha interaktiv tekshiruvda PCR uchun 9-bo‘lim — **“Qanday ishlatiladi — bosqichma-bosqich”** — ochildi. O‘quv sahifasi sarlavhasi ushbu bo‘limga almashdi va progress indikatori `9 / 16` holatini ko‘rsatdi.

Qolgan qurilmalar ham ayni `learningByNumber` ma’lumotlar modeli va `DeviceViewer` komponenti orqali shu standartda render qilinadi.
