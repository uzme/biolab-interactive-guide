# BioLab Interactive Guide — Design Philosophy & Architecture

## Approach Chosen: "Modern Precision Biotech" (Crisp, high-end laboratory interface with deep scientific credibility)

- **Theme Name**: Modern Precision Biotech
- **Very Brief Intro**: A pristine, high-end scientific interface blending deep teal/emerald scientific accents with immaculate white/slate typography, designed for professional biotechnologists and researchers.
- **Probability**: 0.05
- **Design Movement**: Contemporary Swiss Scientific UI & Glassmorphic Precision
- **Core Principles**:
  1. **Uncompromising Clarity**: Every piece of equipment data, technical parameter, and price benchmark is structured with absolute visual hierarchy.
  2. **Structured Learning**: A 16-step curriculum, readable learning progress, manual-grounded workflows, and safe troubleshooting guidance.
  3. **Biotexnolog Aesthetic**: Deep teal, emerald, and clean slate gradients reflecting modern laboratory standards.
- **Color Philosophy**: 
  - Primary: Deep Emerald/Teal (`#0d9488` / `oklch(0.55 0.15 180)`) for precision and biological trust.
  - Secondary: Slate Dark (`#1e293b`) for structural authority.
  - Accent: Vibrant Mint (`#14b8a6`) for interactive highlights and hotspot pulses.
- **Layout Paradigm**: Asymmetric sidebar navigation combined with a curated card catalogue and a long-form, 16-section learning workspace for each instrument.
- **Signature Elements**: Numbered curriculum rails, slim calibration-grid separators, category badge pills, manufacturer/model data bands, and structured financial/import breakdowns.
- **Typography System**: Plus Jakarta Sans is dominant for all headings, labels, and equipment titles; serif display typography is excluded from the core identity.

## Style Decisions

- Prioritize a cold, pristine lab-grade canvas: white, cool slate, translucent glass panels, teal signal accents, and thin technical separators.
- Every equipment card must show at least one scientific specificity cue, such as a model-preview treatment, parameter chip, hotspot marker, or compact technical data band.
- The hero must communicate structured scientific learning immediately through a 16-step curriculum rail, calibration-grid overlay, and precise manual/SOP language rather than functioning only as a promotional banner.
- The visual system uses deep teal for authority, mint only for active learning signals, and sharper cool-slate separators for laboratory-grade contrast.
- Equipment cards use a compact manufacturer/model/manual data band and category-specific instrument glyph; no device 3D, 2D schematic, or hotspot preview is used.
- The hero’s numbered 16-step curriculum rail is a dominant structural element rather than a supporting statistic; the rail anchors the visual transition from scientific understanding to SOP-guided practice.
- The BioLab mark uses a deep-teal precision module, an unmistakable laboratory-symbol lock-up, and a `LAB-01` identifier to distinguish the learning platform from a generic equipment catalogue.
- Catalogue cards carry category-specific glyph colors and deep-teal protocol bands so that their scientific grouping, model context, and 16-step learning scope can be scanned before opening a record.
- The hero opens with the 16-step LAB-01 SOP rail, while every card exposes its model, manual/manufacturer context, and a unique SOP record code before the user opens the full learning page.
