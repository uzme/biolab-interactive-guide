# Expo Go SDK mosligi

2026-08-24 holatida BioLab Mobile dastlab Expo SDK 57 bilan scaffold qilindi. Foydalanuvchi iPhone’dagi Expo Go ilovasi loyiha uchun eski bo‘lgani sabab `Project is incompatible with this version of Expo Go` xatosini qaytardi.

Rasmiy Expo troubleshooting hujjatiga ko‘ra, loyiha SDK versiyasi Expo Go SDK versiyasiga mos bo‘lishi kerak. Shu hujjatda iOS App Store’dagi Expo Go SDK 54 da to‘xtashi va SDK 55 hamda undan yangilari iOS Expo Go’da mavjud emasligi qayd etilgan. Shuning uchun iPhone Expo Go sinovi uchun BioLab Mobile Expo SDK 54 ga moslashtiriladi; SDK 55+ uchun keyinchalik development build talab qilinadi.
